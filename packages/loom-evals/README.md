# loom-declarative-evals

Evaluation runner and the `loom evals` CLI plugin for [Loom](https://github.com/jdbaigorria/loom-dev).

```bash
pip install loom-declarative-evals
```

```python
from loom_evals import LoomEvals

LoomEvals("my_agent").run()
```

The core extra `loom-declarative[evals]` installs this package. `from loom import LoomEvals` is deprecated.
